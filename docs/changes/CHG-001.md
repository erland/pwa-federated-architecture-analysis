# CHG-001 – Tom start och valbara exempel

Användarbeslut 2026-10-28: appen ska vara tom som standard och tillhandahålla några tydligt valbara exempel för att testa hela flödet.

Ett sammanhållet ändringssteg: ta bort automatiskt skapad analystyp, visa startsida utan aktiv konfiguration även när tidigare arbete finns sparat, behåll tidigare data för uttrycklig återöppning, tillhandahåll tre importerbara exempel (Excel, XML, federerat), erbjud egen analystyp från grunden och verifiera hela import-/konfigurationsflödet. Ingen automatisk radering av data.

Done: en ny arbetsyta har inga analystyper/metamodeller/snapshots/körningar; ingen aktiv analys visas efter öppning eller omladdning; alla tre exempel kan väljas explicit och köras efter källimport; egen konfiguration kan skapas, mappas, publiceras och analyseras; tidigare arbetsdata finns kvar efter återöppning. Alla relevanta regressionstester och byggning ska passera. Full projekt-ZIP och ny preview levereras.
